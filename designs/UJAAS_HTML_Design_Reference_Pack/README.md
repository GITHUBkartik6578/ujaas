# UJAAS — HTML Design Reference Pack

## Contents
- `index.html` — gallery of all visual references.
- `pages/` — one responsive HTML viewer page per image (42 pages).
- `assets/` — original image files used by the viewer pages.

## How to use
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Select a reference to view it at a larger size.
4. Give the extracted folder to Claude along with the UJAAS project brief.
5. Ask Claude to implement actual semantic HTML/CSS/JS or React components based on each selected reference, not merely embed the screenshot as a page background.

## Important limitation
These HTML files are **visual reference viewers**. A screenshot is a flattened image; it does not contain the original DOM, CSS, responsive breakpoints, form logic, or editable text layers. Rebuilding the real frontend requires recreating the layout and components from the references. The images are kept intact so Claude can inspect the intended visual direction.

## Data accuracy
Do not treat names, portraits, event dates, issue dates, statistics, phone numbers, email addresses, or addresses visible inside mockups as verified UJAAS data. Use clearly labelled placeholders until the editorial team supplies confirmed information.

## Responsive guidance for implementation
- Test at 390px mobile, tablet, 1366–1440px desktop, and 1920px desktop.
- Prevent horizontal overflow, clipped Devanagari text, overlapping sections, and distorted images.
- Use real responsive image elements and natural content height.
- Respect `prefers-reduced-motion` for scroll animations.
- Keep each page's hero composition and section hierarchy distinct.
